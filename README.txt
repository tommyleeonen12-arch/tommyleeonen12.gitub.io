ONEN TOMMLEE PORTFOLIO
======================

FILES
- index.html  : page content and sections
- styles.css  : dark futuristic responsive design
- script.js   : mobile menu, reveal animations and current year

RUN LOCALLY
1. Extract the ZIP.
2. Open the onen-tommylee-portfolio folder.
3. Double-click index.html to preview it in your browser.
   Recommended: use Visual Studio Code with the Live Server extension.

CUSTOMIZE BEFORE PUBLISHING
- Replace the three sample project cards in index.html with your actual projects.
- Update each "View on GitHub" link to the specific project repository.
- Add your real CV if you later add a Download CV link.
- The contact button opens the visitor's email app using a mailto link.
- Google Fonts requires internet; the page itself is plain HTML, CSS and JavaScript.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository. For a personal site, name it:
   tommyleeonen12.github.io
2. Upload index.html, styles.css and script.js to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait for deployment. Your site should be available at:
   https://tommyleeonen12.github.io/

This is a static website. It does not require Node.js or a backend server.


BRANDING
The Golden Lee Technologies logo is included as golden-lee-technologies-logo.png and is displayed in the navigation bar and footer. Keep this image in the same folder as index.html.
